# تطبيق المتفوق — مشروع Android (Kotlin + Jetpack Compose)

مشروع Android Studio جاهز يطابق شاشات الإعداد اللي صممتها (الحساب، المدة اليومية، وقت المذاكرة، اختيار التطبيقات) مع دعم:

- **العمل بدون إنترنت بالكامل**: كل البيانات (الاسم، الهدف اليومي، وقت المذاكرة، قائمة التطبيقات المقيّدة، الإحصائيات) تُخزّن محليًا على الجهاز عبر Room + SharedPreferences، بدون أي اتصال بخادم.
- **تقييد فعلي للتطبيقات أثناء جلسة التركيز**: عبر Accessibility Service — نفس الأسلوب المستخدم في تطبيقات مثل Forest وFocus To-Do المتوفرة على Google Play.
- **بناء تلقائي بدون كمبيوتر**: المجلد `.github/workflows/build.yml` يخلي GitHub يبني ملف APK تلقائيًا كل مرة ترفع فيها الكود — شوف قسم "البناء بدون كمبيوتر" تحت.

## البناء بدون كمبيوتر (عبر GitHub، من الجوال بالكامل)

1. أنشئ حساب مجاني على [github.com](https://github.com) من متصفح الجوال.
2. أنشئ مستودع (Repository) جديد، خله عام أو خاص حسب رغبتك.
3. ثبّت تطبيق [Termux](https://f-droid.org/packages/com.termux/) من F-Droid (نسخة متجر جوجل قديمة، تجنّبها).
4. افتح Termux ونفّذ الأوامر التالية بالترتيب:
   ```
   pkg install git -y
   termux-setup-storage
   cd ~/storage/downloads
   unzip KhutaaApp.zip
   cd KhutaaApp
   git init
   git remote add origin https://github.com/USERNAME/REPO.git
   git add .
   git commit -m "أول رفع"
   git branch -M main
   git push -u origin main
   ```
   (بدّل `USERNAME/REPO` باسم حسابك واسم المستودع. عند الطلب بكلمة المرور، أنشئ [Personal Access Token](https://github.com/settings/tokens) من إعدادات GitHub واستخدمه بدل كلمة المرور العادية.)
5. روح لصفحة المستودع في المتصفح → تبويب **Actions** → بتلقى عملية بناء شغالة، انتظر لين تخلص (علامة ✅ خضراء).
6. افتح العملية المكتملة → قسم **Artifacts** تحت → حمّل `khutaa-debug-apk`.
7. فك الضغط، وثبّت ملف الـ APK على جوالك (فعّل "تثبيت من مصادر غير معروفة" لتطبيق الملفات أو المتصفح من إعدادات الجوال أول مرة).

## كيف تبنيه (لو صار عندك كمبيوتر لاحقًا)

1. ثبّت [Android Studio](https://developer.android.com/studio) (أحدث إصدار).
2. افتح المجلد `KhutaaApp` كمشروع (File → Open).
3. خلّه يحمّل التبعيات (Gradle Sync) — يحتاج اتصال إنترنت أول مرة فقط لتحميل المكتبات، بعدها التطبيق نفسه يشتغل بدون نت.
4. شغّله على جهاز حقيقي أو محاكي (Run ▶).

## نقاط تحتاج انتباهك قبل النشر

- **أيقونة التطبيق**: وضعت أيقونة مبسّطة مؤقتة. استخدم أداة Image Asset في Android Studio (Right-click على `res` → New → Image Asset) لتصميم أيقونة احترافية.
- **صلاحية "تسهيل الوصول"**: التطبيق يطلب من المستخدم تفعيلها يدويًا من زر داخل الشاشة الرئيسية (هذا إلزامي على أندرويد لأي تطبيق قفل/تركيز، وجوجل بلاي يقبله طالما وضّحت الغرض بوضوح في وصف التطبيق وسياسة الخصوصية — راجع [Google Play Accessibility Policy](https://support.google.com/googleplay/android-developer/answer/10964491)).
- **شاشة "اختيار التطبيقات"** تعرض كل التطبيقات القابلة للتشغيل على الجهاز (بدل قائمة ثابتة زي تيك توك وانستقرام)، لأنها تُقرأ محليًا من الجهاز مباشرة — أدق وتشتغل بدون تحديث يدوي من طرفك.
- ميزات ناقصة تقدر تكمّلها: عرض التطبيقات المقيّدة الحالية عند فتح شاشة التعديل (حاليًا تبدأ فارغة)، تفعيل تلقائي لوضع التركيز في وقت المذاكرة المحدد (الجدولة اليومية)، شاشة تسجيل دخول حقيقية (حاليًا الاسم فقط محليًا بدون كلمة مرور).

## النشر على Google Play

1. أنشئ [حساب مطوّر Google Play](https://play.google.com/console) (رسوم دفعة وحدة حوالي 25 دولار).
2. من Android Studio: Build → Generate Signed Bundle/APK → اختر Android App Bundle، وأنشئ مفتاح توقيع (Keystore) واحتفظ بنسخة منه بأمان — لو ضاع ما تقدر تحدّث التطبيق لاحقًا.
3. ارفع ملف `.aab` الناتج في Google Play Console، واملأ بيانات التطبيق (الوصف، الصور، سياسة الخصوصية — إلزامية لأي تطبيق يستخدم Accessibility Service).
4. جوجل تراجع تطبيقات Accessibility Service بعناية أكبر من التطبيقات العادية؛ جهّز فيديو قصير يوضح كيف تُستخدم الصلاحية داخل التطبيق (متطلب شائع في المراجعة).

## بنية المشروع

```
app/src/main/java/com/khutaa/study/
  MainActivity.kt              — شاشة الدخول + خريطة التنقل بين الشاشات
  ui/screens/                  — كل شاشة إعداد (ترحيب، حساب، مدة، وقت، تطبيقات، الرئيسية)
  ui/theme/                    — الألوان والخطوط
  data/                        — قاعدة بيانات Room (Entities/DAO)، SessionManager، StatsManager
  service/                     — AppBlockerAccessibilityService (كشف فتح تطبيق مقيّد) + BlockOverlayActivity (شاشة التذكير)
```
